# Panto

A responsive furniture ecommerce landing page built with Next.js 16, Tailwind CSS v4, and TypeScript.

**Repository**: [https://github.com/RafikElRahmi/panto.git](https://github.com/RafikElRahmi/panto.git)

## Tech Stack

- Next.js 16 (App Router)
- Tailwind CSS v4
- TypeScript
- pnpm

## Getting Started

```bash
pnpm install
pnpm dev
```

Open [http://localhost:3000](http://localhost:3000).

## Build

```bash
pnpm build
pnpm start
```

## Note on Fonts

The Figma design uses **Gilroy**, a paid font I don't have access to. I used **Montserrat** as a free alternative — it shares very similar geometric characteristics and proportions.
